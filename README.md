# Motores 3D: área da morte

Isso é de ago/2023, da época da faculdade. Coloquei no GitHub em 2026 como registro e deixei como estava.

Atividade de motores 3D que entreguei em agosto de 2023. Tem o jogador, NPCs que vão sendo instanciados (`InstanciarNpcs.cs`) e uma área da morte que destrói quem cai nela (`AreaDaMorte.cs`).

O histórico tem duas versões da mesma noite. A primeira veio do pacote `GustavoDimasMotores.unitypackage` e ainda tinha comentários no código; a segunda é a que entreguei.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.18f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
